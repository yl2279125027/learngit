# 作业5 要求：心理学研究方法

> 来源：课程作业说明《心理学研究方法》（原件 `心理学研究方法.docx`），原文照录。

## （一）作业性质

为综合考察学生对《心理学研究方法》课程核心内容的掌握与应用能力，以及帮助大家提前了解毕业论文的流程，本次课程的作业为完成一份研究计划书，字数不少于 5000 字。

## （二）计划书必须包含的六个部分

1. 题目
2. 引言与文献综述（系统性地检索、阅读、梳理和评价现有文献，确立研究的理论和实证基础）
3. 研究假设（基于文献综述，逻辑清晰地推导出具体、可操作的研究假设）
4. 研究方案（完整地设计一个切实可行的研究方案，包括研究方法、参与者、材料/工具、程序及数据分析计划，并考虑研究伦理）
5. 参考文献

## （三）选题要求

1. 选题必须是心理学领域的相关问题，建议选择你感兴趣的主题。
2. 必须选择实证性课题（即可以通过收集数据来检验的课题）。
3. 选题不宜过大过空，应具体、聚焦，能在课程作业的篇幅内深入探讨。

## （四）学术诚信

1. 严禁任何形式的抄袭、剽窃。所有引用他人的观点、研究结果必须明确注明出处。
2. 参考文献的引用格式必须统一遵循 APA（美国心理学会）第 7 版格式规范。
3. 提交作业时，请提交查重报告。

## （五）格式要求

| 项目 | 要求 |
|---|---|
| 字体 | 中文宋体；英文及数字 Times New Roman |
| 大标题 | 三号，加粗 |
| 一级标题（如 1,2,3） | 四号，加粗 |
| 二级标题（如 3.1, 3.2） | 小四，加粗 |
| 正文 | 小四 |
| 参考文献 | 五号或小五 |
| 行距 | 正文 1.5 倍行距，参考文献单倍行距 |
| 段落 | 首行缩进 2 字符 |
| 页边距 | 普通（上下 2.54cm，左右 3.18cm） |
| 提交形式 | Word 文档上传 |

## （六）选题

用户在习题文档中自定选题方向：积极心理学对职高（中职）学生学习动力的提升。
