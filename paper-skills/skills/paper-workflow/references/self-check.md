## 1. 检查项（规则 ID）

### 硬性（HARD，必须改，exit 1）

| ID | 抓什么 | 典型命中 | 怎么改 |
|---|---|---|---|
| S1 套话承接 | 据此 / 由此可见 / 由此而来 / 综上所述 / 需要说明的是 / 这说明 / 这意味着 / 这也解释了 / 上述…提示 / 值得注意的是 / 可以看出 | 「据此，学校改进应……」「测量上的困难由此而来」 | 删承接语，直接陈述；或把结论拆成事实后再下判断 |
| S2 对举套式 | 不是…而是 / 并非…而是 / 不仅…也 / 不仅仅 / 不止于 / 并不等于 | 「期望的作用不止于一次评价」「并不等于家长期望」 | 只说它是什么，不用对照句式 |
| S3 无据断言 | 无疑 / 必然 / 必将 / 必定 / 一定会 / 毫无疑问 / 彻底 / 完全避免 / 完成了自我实现 / 就完成了 | 「偏差也就完成了自我实现」 | 用「可能」「在本文所引研究中」限定；超出文献的说法删掉 |
| S4 英文翻译腔 | this paper examines / shared concern / should therefore / plays a key role / furthermore / moreover / delve / pivotal / translate…into / constrain the use / based on…this paper | 英文摘要「School improvement should therefore translate…」 | 英文摘要按英文学术写法重写，主语是研究对象，不逐句对译 |
| S5 破折号/问号 | `——` `？` `?` | — | 破折号改冒号或逗号；问号改陈述句 |
| S6 年份与文献不一致 | 正文「YYYY—ZZZZ年」的终止年 > 参考文献最晚出版年 | 正文写 2021—2026 年，参考文献最晚 2025 | 年份范围改成与参考文献一致，或补文献 |

### 警告（WARN，不阻断，逐条判断）

| ID | 抓什么 | 处理 |
|---|---|---|
| W1 金句收束 | 难的是 / 关键在于 / 问题在于 / 难点在于 / 取决于 / 恰恰是 / 一旦…就 / 越…越 | 删掉或并入上一句；「取决于细节」换成具体条件 |
| W2 既…也 | 既…也（无标点相隔） | 拆成两句，或只保留一边 |
| W3 对称连接 | 一方面 / 另一方面 | 同段只保留一组，或改为具体并列事实 |
| W4 开场套话 | 「本文以……为基础」「本文将」 | 只留一处（摘要或引言），正文不重复开场 |
| W5 长句链 | 单句 ≥ 200 字 | 拆成两三句；先给结论再给依据。阈值 200 而非 120：人类样本中常见 200 字以上复句，120 过严 |
| W6 整齐枚举 | 同段 ≥2 处「N个/N类/N种/N轮」；全文每千字 > 3 处 | 只保留真正需要计数的一处，其余用具体事例或动作代替 |

> 脚本内部还有 `ENUM` 正则与阈值（`ENUM_PER_PARA_MAX=1`、`ENUM_DENSITY_MAX=3.0`），调阈值只改脚本常量，不要在稿子里为了过检而硬凑。

## 2. 修复循环（每次改稿后都要跑）

```bash
PY=/Users/101bjb0413/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/python/bin/python3
cd /Users/101bjb0413/Desktop/work/tmp/assignments/作业N_<短名>

# 1) 自查门（写完正文后第一步）
$PY ../_shared/check_selfcheck.py --md 作业N_paper.md --json work/selfcheck.json   # exit 0 才往下走

# 2) 其他门（都要过）
$PY ../_shared/check_paper_rules.py --md 作业N_paper.md --refs 12 --min-chars 3000 --ref-style template
$PY ../_shared/check_style.py --md 作业N_paper.md          # 14 项

# 3) 渲染后复验 docx（渲染后再跑一次自查，别只查 md）
$PY ../_shared/render_zuoye_docx.py --md 作业N_paper.md --out 作业N_论文.docx --ref-style template
$PY ../_shared/check_selfcheck.py --docx 作业N_论文.docx
$PY work/check_paper_docx.py 作业N_论文.docx               # 50 项结构断言（可传路径）
```

循环规则：
1. 逐条处理 HARD：删承接语、改结构、补事实或删掉断言。**不要只换同义词**（「据此」换成「因此」等于没改）。
2. 复跑自查，直到 HARD 为 0。
3. WARN 逐条判断：能改就改；改不了的（例如必须保留的长句）在交付说明里写明理由。
4. 改完后核对引用：每段的 `[n]` 集合不变，编号按首次出现仍是 1..N。

```bash
# 引用不变性核对：对比改前改后每段的引用集合
$PY - <<'EOF'
import re
def cites(p):
    t=open(p,encoding='utf-8').read()
    body=t[t.index('## 一、'):t.index('## 参考文献')]
    return [sorted(set(map(int,re.findall(r'\[(\d+)\]',x)))) for x in body.splitlines() if re.search(r'\[\d+\]',x)]
print("改前 == 改后:", cites('work/original/作业N_paper_v0.md') == cites('作业N_paper.md'))
EOF
```

## 3. 改写原则（不是换词）

| 情形 | 做法 | 本次示例 |
|---|---|---|
| 承接语后面跟的是结论 | 直接写结论，删承接 | 「据此，学校改进应把高期望落为……」→「学校可以把期望落实为……」 |
| 对举句式 | 正向陈述 | 「期望不是评判，而是共同建构的过程」→「期望是在师生互动中被共同建构的关系性过程」 |
| 金句收束 | 删，或并入上一句 | 「动作越具体，越容易被检查」→ 删 |
| 「难的是」「取决于」 | 写具体条件 | 「培训能否落地，取决于细节」→「培训能否落地，要看这些细节是否真的改变了课堂」 |
| 论证连接 | 用文献的事实串起来 | 「这说明……」→ 直接写「2024年的研究显示……」 |
| 英文摘要 | 重写，不对译 | 「School improvement should therefore translate…」→「Schools can respond by turning expectations into observable teaching practices…」 |
| 年份范围 | 与参考文献一致 | 「2021—2026年」→「2021—2025年」（参考文献最晚 2025） |

**不能动的东西**：引用编号与位置、参考文献条目、样本量/卷期页等事实数字、摘录原文。

**数字来源**：只能来自文献原文或参考条目。可以从参考条目取年份（如「2021年的一篇硕士论文」），不能凭空加数字凑「数字句子占比」。

## 4. 文风门与自查门的关系

- `check_style.py` 管「统计画像像不像人类样本」（句长、段长、逗号、分号、数字密度、模板词）。
- `check_selfcheck.py` 管「句式套路」（承接语、对举、金句、枚举、英文翻译腔、事实一致）。
- 两者都要过。文风门的阈值会推着句子变长，自查门的 W5 会拦住超过 200 字的复句，两者需要一起平衡。
- 本次修订的做法：先用自查门清掉套路句，再用文风门的 `句长/短句/数字句` 指标检查节奏，最后两门都归零。

## 5. 边界

- 自查降低的是「套路化」风险，**不是保证**。检测器结果仅供参考，报告自身也写明「AIGC 占比与文章质量无必然联系，检测结果仅为参考」。
- 不为过检编造内容、不伪造个人经历、不把数据写得比文献更确定。
- 学校如要求披露 AI 辅助写作，按学校规定处理，不在稿件里隐去。
- 自查门通过后仍要人工通读一遍：拼接式改写容易出现语病与重复措辞。
