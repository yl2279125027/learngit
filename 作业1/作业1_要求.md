# 作业1 要求：学校教育和社会专题

> 来源：课程作业说明《学校教育和社会专题》（原件 `学校教育和社会专题.docx`），原文照录。

请任选一个与学校教育或教育社会学相关的选题撰写一篇 3000 字以上的论文，具体规定如下：

1. 论文的一般结构包括中英文标题、中英文摘要、中英文关键词及正文，具体格式要求如下：

| 部分 | 格式要求 |
|---|---|
| 标题 | 宋体小二加粗 |
| 摘要（200 个字左右）、关键词（3-5 个） | 宋体五号 |
| Abstract（100 words）、Keywords（3-5） | Times New Roman 五号 |
| 正文（引言、提出问题、分析问题、解决问题、结论） | 宋体小四 |
| 第一层次：一、二、三、四 | 宋体小三号加粗 |
| 第二层次：（一）（二）（三）（四） | 宋体四号加粗 |
| 第三层次：1. 2. 3. 4. | 宋体小四加粗 |
| 参考文献 | 一手文献、最近 5 年的文献，原则上不少于 10 篇 |

2. 全文都是 1.5 倍行距。

（请用 word 文档上传）
