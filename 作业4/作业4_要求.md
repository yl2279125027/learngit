# 作业4 要求：普通心理学

> 来源：课程作业说明《普通心理学》（用户在对话中提供的原文），原文照录。

## （一）选题方向（任选其一）

1、理论应用类：选取普通心理学中的某一理论（如知觉理论、记忆模型、动机理论、情绪理论、人格理论等），结合您所在行业或工作岗位的实际案例进行分析，阐述该理论对理解或解决实际问题的启示。

2、专题综述类：围绕普通心理学某一核心主题（如"注意的选择机制研究进展""工作记忆的模型演变""情绪调节的策略与神经基础"等），对国内外相关研究进行系统综述。

3、现象分析类：针对日常生活或社会热点中的某一心理现象，运用普通心理学的多个章节知识（如感知、记忆、思维、情绪、动机等）进行综合分析与解释。

参考选题示例：

- 社交媒体信息过载对注意与记忆的影响——基于认知心理学视角
- 组织管理中员工激励的动机理论应用研究
- 创伤后应激障碍（PTSD）中的记忆机制分析

## （二）格式规范

| 项目 | 要求 |
|---|---|
| 字数 | 3000–5000 字（含参考文献） |
| 题目 | 自拟，要求准确、简洁，能反映论文核心内容 |
| 摘要 | 200–300 字，概括研究目的、方法/思路、主要结论 |
| 关键词 | 3–5 个 |
| 正文结构 | 引言（问题提出）→ 理论阐述/文献回顾 → 案例分析/论证 → 结论与启示 |
| 参考文献 | 不少于 10 篇，其中近 5 年文献不少于 5 篇；格式统一采用 APA 第 7 版格式 |
| 其他 | 正文小四号宋体，1.5 倍行距；A4 纸排版 |
